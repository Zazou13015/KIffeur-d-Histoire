# Illustrations des événements

Dessins SVG au format décidé dans `docs/prd.md` (« Illustrations »), nommés `<id de l'événement>.svg`. Ce sont des créations du projet : aucune licence tierce à suivre.

**Lot 1 (30 fichiers)** : les 30 premiers événements du pack « 50 dates incontournables ». Les autres événements du pack et les événements scolaires suivront par lots, après relecture de celui-ci. Un événement sans fichier affiche le pictogramme de son thème.

Envoi en base de test : `npm run content:illustrations` (crée le bucket `histoire-illustrations` et renseigne `image_path`). Pas d'envoi en production sans l'accord de Maxou et Antonin.
